Agent builder
Quick start

Insure every fetch

Install the SDK, fund escrow once, then call merchants by origin URL — premiums and refunds settle automatically.

npm install x500-agent-sdk Requires Node.js 18+
agent.ts 
import { createX500 } from "x500-agent-sdk";

const x500 = createX500({
  network: "testnet",
  address: process.env.X500_AGENT_ADDRESS!,
  mnemonic: process.env.ALGORAND_AGENT_MNEMONIC!,
});

// 1. Fund insurance escrow once
await x500.setup({ escrowMicroAlgos: 3_000_000n });

// 2. Call a registered merchant by origin URL
const res = await x500.fetch(
  "https://your-merchant.example/paid/weather?city=Paris",
);

console.log(res.status, await res.text());
await x500.close();
